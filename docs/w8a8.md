# 零拷贝与 W8A8 副本（重排、Qwen3 嵌入、Decider）

`common/` 是这三类模型共用的模块：

| 文件 | 内容 |
| --- | --- |
| `common/mlx_w8a8.py` | W8A8 线性层（256 宽 Hadamard 旋转 + 按行 INT8 权重与激活，M5 TensorOps INT8 GEMM）；页对齐 safetensors 的写入（`save`）和零拷贝读取（`load`） |
| `common/qwen3_w8a8.py` | 把 mlx_lm Qwen3 骨干（重排、嵌入）写成零拷贝或 W8A8 目录 |
| `common/w8a8_kernels/` | GEMM 内核，来自 mlx-serve（David Dalcu，MIT，见该目录的 `LICENSE` 和 `SOURCE.md`），经 mflux fork 原样复制 |
| `common/w8a8_selftest.py` | 层误差、零拷贝逐位读取、GEMM 速度自检 |

W8A8 内核用 M5 的 Metal TensorOps INT8 指令；其他机型未验证。数据见[性能报告](performance.md)。

**原则：W8A8 只用在能提速的地方。** INT8 激活带来额外误差，只有在实测确实变快的层或模型上才换；小矩阵（0.6B 重排、
0.6B 嵌入、voyage）、只跑一次或占比很小的阶段（例如 Qwen-Image 的文本编码器）保持 BF16／FP16。只为省内存的权重量化
（Q8_0 等）是另一回事，要单独说明理由。W8A8 都做成单独的 `-int8` 入口，默认入口保持精确。

### 逐类检查标准

每个 `-int8` 入口都按投影类别（q/k/v、o、gate/up、down、线性注意力 in_proj / out_proj 等）逐类决定，不整模型一刀切：

1. 先看端到端提速；再逐类测这一类自己快多少、换回浮点后端到端多出多少时间（它在提速里的占比）。
2. 逐类单独换回浮点（或换回只量化权重），用大样本的平均误差和排序（几百到上千对，不只看十几条用例的最大值）看误差来自哪一类。
3. 不提速的类保持浮点；提速很小、但误差占大头的类也换回浮点。组合之间误差不可加，最终组合要整体实测。
4. 只为省内存的权重量化（Q8_0、8-bit）是另一个理由，不受此约束。

服务里的开关：

| 服务 | 参数 | 作用 |
| --- | --- | --- |
| `rerank/server.py`、`embedding/qwen3/server.py` | `--w8a8-classes q_proj,...,up_proj --float-model <zc 目录>` | 只把列出的类用 W8A8，其余类从零拷贝浮点副本读（`common/qwen3_w8a8.py` 的 `load_mixed`） |
| `decisions/decider/server.py` | `--w8a8 --w8a8-names ...` | Decider 只量化列出的投影（默认全部 `W8A8_NAMES`） |
| `decisions/jev/server.py` | `--quant w8a8 --w8a8-skip ...` | 列出的类保持 8-bit 只量化权重 |

当前结果：重排／嵌入 4B 的 `down_proj` 用浮点；Decider 的 `down_proj` 用 FP16；elephant-1 的 `in_proj_z`、mammoth-1 的 `out_proj` 保持 8-bit；
重排／嵌入 8B、Qwen-Image DiT、H3 图片与视频的 DiT 线性层每类都提速、误差分散，全部保留 W8A8。数据见[性能报告](performance.md)。

## 1. 源权重（MLX 格式）

| 模型 | 源目录 | 生成方式 |
| --- | --- | --- |
| Qwen3-Reranker 0.6B / 4B | `qwen3-reranker/mlx-{0.6b,4b}-bf16` | `mlx_lm.convert --hf-path Qwen/Qwen3-Reranker-4B --mlx-path ... --dtype bfloat16` |
| Qwen3-Reranker 8B | `qwen3-reranker/mlx-8b-q8_0` | `rerank/q8_0_to_mlx.py HF_DIR OUT_DIR --act-dtype float16`（见 [rerank.md](rerank.md)） |
| Qwen3-Embedding 0.6B / 4B | `qwen3-embedding/mlx-{0.6b,4b}-fp16` | `embedding/qwen3/convert_embed.py HF_DIR OUT_DIR --fp16` |
| Qwen3-Embedding 8B | `qwen3-embedding/mlx-8b-q8_0` | `embedding/qwen3/convert_embed.py HF_DIR OUT_DIR --q8_0` |
| voyage-4-nano | `voyage-4-nano/mlx-fp16` | `embedding/qwen3/convert_embed.py HF_DIR OUT_DIR --fp16` |

HF_DIR 是 `hf download Qwen/Qwen3-Reranker-4B` 等下载的官方目录；转换都在 CPU 上运行。

## 2. 零拷贝副本（默认入口）

同样的权重重写为一个页对齐的标准 safetensors，加载时直接从页缓存映射，数值与源目录完全相同。

```sh
PY=.venv/bin/python; M="$HOME/models"     # 换成实际的模型目录
$PY common/qwen3_w8a8.py rerank "$M/qwen3-reranker/mlx-0.6b-bf16" "$M/qwen3-reranker/zc-0.6b-bf16" --float
$PY common/qwen3_w8a8.py rerank "$M/qwen3-reranker/mlx-4b-bf16"   "$M/qwen3-reranker/zc-4b-bf16"   --float
$PY common/qwen3_w8a8.py rerank "$M/qwen3-reranker/mlx-8b-q8_0"   "$M/qwen3-reranker/zc-8b-q8_0"   --float
$PY common/qwen3_w8a8.py embed  "$M/qwen3-embedding/mlx-0.6b-fp16" "$M/qwen3-embedding/zc-0.6b-fp16" --float
$PY common/qwen3_w8a8.py embed  "$M/qwen3-embedding/mlx-4b-fp16"   "$M/qwen3-embedding/zc-4b-fp16"   --float
$PY common/qwen3_w8a8.py embed  "$M/qwen3-embedding/mlx-8b-q8_0"   "$M/qwen3-embedding/zc-8b-q8_0"   --float
# voyage-4-nano 改回 BF16：FP16 激活在部分 300 token 以上的输入上溢出（NaN 向量）
$PY common/qwen3_w8a8.py embed  "$M/voyage-4-nano/mlx-fp16"        "$M/voyage-4-nano/zc-bf16"        --float --dtype bfloat16
```

- 重排副本只保留输出头里 "yes"/"no" 两行（服务只读这两行）。
- 生成后源目录 `mlx-*` 不再被服务读取，可以留作重新转换的来源。

## 3. W8A8 副本（`-int8` 入口）

```sh
$PY common/qwen3_w8a8.py rerank "$M/qwen3-reranker/mlx-4b-bf16"    "$M/qwen3-reranker/w8a8-4b"
$PY common/qwen3_w8a8.py rerank "$M/qwen3-reranker/mlx-8b-q8_0"    "$M/qwen3-reranker/w8a8-8b"
$PY common/qwen3_w8a8.py embed  "$M/qwen3-embedding/mlx-4b-fp16"   "$M/qwen3-embedding/w8a8-4b"
$PY common/qwen3_w8a8.py embed  "$M/qwen3-embedding/mlx-8b-q8_0"   "$M/qwen3-embedding/w8a8-8b"
$PY common/w8a8_selftest.py "$M/qwen3-reranker/w8a8-4b/model.safetensors"   # 可选自检
```

- q/k/v/o、gate/up/down 改为 W8A8；词嵌入和 norm 保持原精度。8B 的 Q8_0 源先反量化再转。
- 4B 的 `-int8` 入口运行时再用 `--w8a8-classes` 把 `down_proj` 换回零拷贝浮点副本（见下面的逐类检查标准），所以 `zc-4b-*` 也要在。
- 0.6B 和 voyage 不做 W8A8：矩阵太小，几乎不提速，误差却大很多。
- `-int8` 嵌入入口的向量与精确入口不通用，换入口要重建索引。

## 4. Perplexity Decider（`pplx-decider-flash-int8`）

不需要另存文件：服务带 `--w8a8` 时，读官方 BF16 权重的同时把语言模型的投影量化为 W8A8（加载峰值 4.87 GiB）。
权重准备见 [decisions.md](decisions.md)。
